# Delta Green module shortlist (2026-10-25)

Screening of the official Arc Dream Foundry VTT modules for the next campaign.
Criteria: modern real-world grounding, fit for a single agent, investigation and
relationship density, usefulness to the offscreen world engine, Foundry
currency, and length.

## The official Foundry line

Thirteen packages from Arc Dream: Convergence (played), PX Poker Night,
Observer Effect, The Star Chamber, Extremophilia, Reverberations, Jack Frost,
the Agent's Handbook, Music from a Darkened Room, Need to Know, Viscid, Puppet
Shows and Shadow Plays, and Operation FULMINATE.

Foundry compatibility notes: our world runs the `deltagreen` system at 1.7.0 on
core 14. The current system is 2.0.1. Newer module builds are verified on core
13; the older ones (Puppet Shows, FULMINATE) are verified only on 11. Update the
system and test-load a module before committing to a campaign.

## Recommendation

**Extremophilia** is the top pick. It is a modern, multi-session investigation
with a corporate antagonist, a real setting (Helena, Montana), a public-health
crisis the agent can work like a federal case, and a strong offscreen engine
shape: the company, the infected, the CDC, and the local authorities all run on
clocks. It gives a solo agent room to build allies and make institutional
choices, which is where this table is strongest. It is one scenario, not a
short story, and it has a clear escalation and a real ending.

**Music from a Darkened Room** is the best short, solo pressure cooker. It is
written for 1 to 4 agents, which fits this table better than any other module in
the line. One house, fifty years of deaths, a deep history to uncover, and
almost no map dependence. It is the strongest pure atmosphere in the line and it
would play beautifully with an AI GM. It is short, likely two to four sessions,
so treat it as a palate cleanser or an interlude, not a campaign.

**Puppet Shows and Shadow Plays** is the most distinctive setting on the list:
1990s Arizona, the San Carlos Apache reservation, thirteen disappearances along
the stretch of Highway 70 the press calls the Devil's Highway, and the FBI
walking into a jurisdiction that does not want them. It fits an FBI agent
perfectly and gives a real cultural and institutional texture that no fantasy
setting can. The risk is age. It began as an introductory scenario, its Foundry
build is the oldest in the line, and its treatment of the reservation needs
careful handling so it does not slide into period cliché.

## Honorable mentions

- **Observer Effect.** A contained physics-lab investigation, roughly six hours
  of play. Excellent single-location pressure, but it brushes the science
  fiction register this table wants to avoid.
- **Operation FULMINATE.** Yosemite, a missing child returned after sixteen
  years, a ranger station and a trailhead. Strong modern procedural hook, short,
  ideal for one agent. Verified only on core 11.
- **Need to Know / Last Things Last.** The best possible one-night opener for a
  new agent or a new player. Not a campaign.

## Not for this table

- **The Star Chamber.** Brilliant structure, but the players run secondary
  agents in flashbacks, not their own character.
- **Jack Frost.** Sprawling, with a large cast and MAJESTIC-side pregens.
- **PX Poker Night.** One night, pregenerated characters.
- **Viscid.** Strong, but it turns into a containment operation and the bio
  horror leans on a familiar register.
- **Reverberations.** Thin for a campaign.
- **Convergence.** Played.

## Prerequisites before the next campaign

1. Update the DG system from 1.7.0 to 2.0.1, then verify the actor and items
   migrated and the dossiers still open.
2. Build the first scene with its tokens, since the bridge cannot create scenes.
3. Decide the solo-agent scaling for the chosen module: which NPCs become the
   standing allies, and which scenes assume a team of four.
4. Run the Pre-Game Protocol before the first session. Read the whole module,
   write the prep, start the clock and the ledger.
